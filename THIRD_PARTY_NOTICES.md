# Dependency dan lesen pihak ketiga

Game menggunakan [Three.js](https://github.com/mrdoob/three.js) (MIT), [Vite](https://github.com/vitejs/vite) (MIT), [Vitest](https://github.com/vitest-dev/vitest) (MIT), [Playwright](https://github.com/microsoft/playwright) (Apache-2.0), dan [ESLint](https://github.com/eslint/eslint) (MIT). Lesen lengkap untuk pakej yang dipasang tersedia dalam direktori `node_modules` masing-masing dan metadata `package-lock.json`.

Tekstur dan ikon game dihasilkan melalui kod projek. Tiada font luar atau aset game pihak ketiga diperlukan semasa runtime.
